- SidebarInset 成为 Console 唯一 `main` landmark 和稳定 skip target，页面内容统一使用普通布局容器。
- Header、Command、Sidebar 导航与用户摘要按官方 shadcn/ui 组合职责拆分。
- 无执行行为的创建按钮、详情菜单项和用户菜单项不再渲染。
- DataGrid 首列不可隐藏，初始空态和搜索空态分离。
- 桌面保留 TanStack Table；移动端使用官方 Sheet 展示行详情和真实详情链接。
- Dashboard 最近审计在移动端使用紧凑列表，避免桌面表格被裁切。
- 详情状态统一为中文展示。
- reviewer 复核后将桌面 inset 高度改为 `calc(100svh - 1rem)`，消除外边距叠加造成的
  页面级纵向溢出。
- skip target 移到 Header 之后的内容滚动容器，使跳转真正绕过 Header 控件。
- 仅影响桌面表格的“列设置”在移动端隐藏，避免移动 Sheet 与桌面列状态产生不一致。
