# PRD-003：IAM 与 Site 完整管理体验

## 1. 定位

Kokoro Admin 是统一管理后台。IAM 与 Site 是首个完整管理域，不是运营看板、技术演示页或将
所有能力铺在同一页面的控制台。平台管理员应能稳定、快速地完成身份、租户、权限、安全和
审计工作；具备 Site 管理权限的用户从产品侧进入时，只能看到当前 Site 范围。

界面固定使用 Next.js App Router、Ant Design 6 和 Pro Components。后台框架已有的布局、表格、
筛选、表单、描述、Drawer、权限树和反馈能力不得自行重写。

## 2. 用户与权限入口

| 用户 | 可见能力 |
|---|---|
| 普通用户 | 不显示管理入口，直接访问管理路由返回 403。 |
| Site 管理员/Owner | 显示当前 Site 管理入口，只能访问当前 `site_id`。 |
| 平台管理员 | 独立部署入口与产品内入口均可用，可显式跨 Site/Organization 管理。 |

平台管理员只能由 IAM bootstrap/reset 流程管理。开发注册插件只在 dev/test 显示，生产构建
不可发现、不可调用。登录支持账号密码和邮件；注册不提供公开账号密码表单。

```text

- 菜单与路由
- 授权检查

- 安全事件
```

菜单只能在对应 route、generated RPC、服务端授权、审计和自动化测试全部存在后注册。未实现
的后端能力不得以空页面、假统计或禁用按钮占位。

## 4. 页面结构

- 列表页：`PageContainer + QueryFilter + ProTable`；常用筛选一行展示，高级筛选折叠。
- 详情页：紧凑摘要头；概览、成员、角色、Session、审计使用 Tabs 分区，不纵向全部展开。
- 少字段编辑：`ModalForm`；复杂授权：Drawer；危险命令：确认对话框、原因和版本校验。
- 权限页：角色列表与分组权限树双栏，底部固定变更摘要与保存命令。
- 日志页：筛选表格和详情 Drawer，结构化展示字段，不直接倾倒 JSON。
- 工作台：只展示来自真实 RPC 的状态、风险和待处理项，不制造指标。

## 5. 视觉方向

- 浅色、高密度、克制的企业后台；信息层级来自网格、分隔和留白。
- 画布 `#f5f7fa`、表面 `#ffffff`、正文 `#1f2937`、次文 `#667085`、边框 `#e5e7eb`、主色
  `#1677ff`；成功、告警、危险色仅用于语义状态。
- 侧栏 216px、顶栏 56px、桌面内容边距 20–24px，业务组件默认 `size="small"`。
- 圆角 6px，卡片最大 8px；页面 section 不做漂浮卡片，禁止卡片嵌套。
- 菜单图标 18px、命令图标 16px；使用项目已安装图标库，陌生图标提供 Tooltip。
- 页面标题 20px、section 标题 16px、正文 14px、辅助文字 12px；字号不随 viewport 缩放。
- 路由、Tab、登录方式和筛选切换不得改变壳层基准、表格起点和主命令位置。

## 6. 业务页面

### 用户与管理员

搜索、状态筛选、详情、停用/恢复、软删除/恢复、Session 撤销、平台角色只读展示和关联
Site/Organization。平台管理员创建与密码重置跳转到明确的脚本流程说明，不提供越权 UI。

### Site

Site 搜索、状态、详情、创建、重命名、暂停/恢复、软删除/恢复、成员完整生命周期、Owner
连续性、角色分配、当前权限检查、相关安全事件和选择当前 Site。

### Organization

保持与 Site 完全独立的组织、成员、角色和授权页面，不使用“租户/Site”别名。

### 权限与菜单

权限目录按领域/资源分组。角色展示权限闭包和影响成员。菜单可见性来自稳定权限键映射，前端
隐藏菜单不是授权边界，Server Action 仍调用 IAM 实时授权。

### 日志与安全

登录日志、操作日志和安全事件在信息架构中独立。当前后端只注册已经实现的安全事件页面；
其他页面必须等待后端契约完成。安全事件支持 Site、Organization、Actor、Target、Kind、Command
和时间范围筛选，并显示全过滤集统计。

## 7. 组件与状态

每个数据页面必须具备 loading、empty、error、403、404、version conflict、deleted 和 partial
状态。每个命令具备提交中、禁止重复点击、幂等重放、失败保留输入、成功刷新和焦点恢复。

后端返回稳定 error code 与 message；前端按 code 决定字段错误、Toast、Alert、冲突刷新或权限
页面，不解析错误字符串决定业务逻辑。

## 8. 验收

1. 所有菜单均有真实业务闭环，无占位页和假数据。
2. 1440×1000、1024×768、390×844 下无横向页面滚动、重叠、截断和布局跳动。
3. 键盘可完成导航、筛选、表单、权限树和确认对话框，焦点状态符合 WCAG 2.2 AA。
4. 中文和英文最长文案不破坏按钮、Tab、Breadcrumb、表格和 Drawer。
5. 每个业务环节通过组件、集成、安全和真实 RPC 测试。
6. 两轮可见 Chromium E2E 使用 fresh fixture，记录分类、整体状态、本地/UTC 时间、步骤、截图、
   RPC、日志和 SQL 证据，零跳过、零 retry。
