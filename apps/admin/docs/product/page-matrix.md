# Admin 页面矩阵

状态：产品规格冻结，页面尚未实现与验收。

本矩阵定义页面目标态。权限列描述前端必须消费的语义能力；稳定能力码以冻结 API 与权限矩阵
为准，页面不得自行推导或拼接能力码。

## 1. 全局壳层

| 区域 | 任务 | 状态 | 操作 | 权限显示 | 响应式 | 验收 |
|---|---|---|---|---|---|---|
| 登录壳层 | 识别产品、选择认证方式、完成登录 | 初始、提交中、统一失败、回调中、服务不可用 | 密码登录、可用时邮件登录 | 已登录且有管理能力时跳转；无能力进入 403 | 单列；移动端表单全宽且不溢出 | 无公开注册；错误不枚举账号；键盘与密码管理器可用 |
| 应用壳层 | 导航、面包屑、全局搜索入口、主题和账号菜单 | 加载、在线、服务降级、会话失效 | 展开侧栏、切换主题、退出 | 菜单按能力投影；路由服务端再校验 | 桌面固定侧栏；平板折叠；移动端 Drawer | 路由切换壳层不跳动；刷新无 FOUC；无 Demo 菜单 |
| 全局反馈 | 统一呈现请求与命令结果 | pending、success、validation、conflict、forbidden、unavailable | 重试、刷新、返回允许页面 | 禁止状态不渲染受限数据 | Toast/Alert 不遮挡主操作 | 不解析错误文案；焦点回到错误字段或结果摘要 |

## 2. 页面与工作区

| 页面/路由 | 管理任务 | 必备状态 | 主要操作 | 权限显示 | 响应式 | 验收重点 |
|---|---|---|---|---|---|---|
| Dashboard `/` | 扫描用户、组织、Site、活跃会话、安全事件和待处理异常 | 骨架、正常、部分数据、无事件、失败 | 刷新、按摘要跳转到预置筛选页 | 只显示可读取领域；不可操作指标不伪装成按钮 | 桌面摘要网格与活动双栏；移动端单列 | 数字和时间窗全部来自 API；无前端风险推断和示例趋势 |
| 用户 `/users` | 搜索、筛选、排序、分页和选择用户 | 骨架、空、筛选为空、失败、403 | 打开详情、新建入口仅在契约允许时显示、批量任务仅在真实支持时显示 | 读能力控制页面；写能力逐项控制命令 | 桌面高密度表格；移动端关键列加详情 Sheet | URL 恢复筛选；稳定行键；无无限列表；无无效批量按钮 |
| 用户详情 `/users/[id]` | 查看身份、关联范围、角色、会话和审计上下文 | 加载、404、403、active、suspended、deleted、partial | 停用、恢复、软删除、恢复删除、撤销会话、跳转关联对象 | 每个动作绑定精确能力；平台角色按契约只读或可改 | 桌面摘要加 Tabs；移动端单列与底部安全操作区 | 危险操作需原因和确认；刷新后显示权威状态；不展示 Token |
| 组织 `/organizations` | 搜索、筛选、分页和创建 Organization | 骨架、空、筛选为空、失败、403 | 创建、打开详情、恢复已删除项 | 读、创建、恢复分别投影 | 表格在移动端收敛为关键字段和行菜单 | Slug/状态显示一致；删除项默认隐藏且可显式筛选 |
| 组织详情 `/organizations/[id]` | 管理基本信息、成员、角色与相关审计 | 加载、404、403、active、deleted、partial | 编辑、软删除、恢复、切换 Overview/Members/Roles/Audit | Tab 和命令分别按范围能力显示 | 桌面 Tabs 保持表格起点；移动端 Tabs 可滚动且不改变壳层 | Organization 不使用 Site 别名；深链 Tab 可刷新恢复 |
| 组织成员 Tab | 管理加入、角色、状态和成员生命周期 | 骨架、空、筛选为空、last-owner、conflict | 添加、改角色、停用、恢复、移除、恢复删除 | 每个成员命令独立投影；不可分配角色不进入选项 | 表格转紧凑列表，编辑使用 Sheet | 跨范围 ID 不泄露；last-owner 失败保留原状态和输入 |
| Site `/sites` | 搜索、筛选、分页和创建 Site | 骨架、空、筛选为空、失败、403 | 创建、打开详情、暂停/恢复入口按上下文提供 | 平台读写与当前 Site 能力分开投影 | 与组织列表保持同一表格模式 | Site 是独立领域；范围切换进入 URL；无组织概念复用文案 |
| Site 详情 `/sites/[id]` | 管理基本信息、成员、角色、权限结果和审计 | 加载、404、403、active、suspended、deleted、partial | 编辑、暂停、恢复、软删除、恢复、切换 Tabs | 平台管理员与当前 Site 管理员看到各自允许范围 | 桌面主内容加 Tabs；移动端单列和 Sheet | 当前 Site 范围贯穿所有请求；越界得到 403 而非空数据 |
| Site 成员 Tab | 管理 Site 成员生命周期和角色分配 | 骨架、空、筛选为空、owner-continuity、conflict | 添加、改角色、停用、恢复、移除、恢复删除 | 命令按钮使用精确 Site 能力 | 复用成员工作区，字段按 Site 配置 | 不复制组织成员组件；范围参数和文案明确为 Site |
| 角色与权限 `/roles` | 选择 Organization/Site 范围，管理角色和权限集合 | 范围未选、加载、空角色、active、deleted、conflict | 创建、编辑、保存完整权限集、软删除、恢复 | 范围读取、角色写入、权限写入分别投影；内置角色只读 | 桌面角色列表加权限树双栏；窄屏按步骤或 Sheet 展示 | 复用唯一 RoleWorkspace；显示成员使用量；删除角色不可分配 |
| 权限诊断 `/access` | 对主体、范围、资源和操作执行实时授权检查 | 未输入、校验中、allow、deny、unavailable、stale | 选择条件、执行检查、复制关联 ID、跳转主体 | 仅有诊断读取能力时显示；结果不产生写操作 | 桌面条件区加结果区；移动端纵向步骤 | 条件改变立即标记旧结果失效；结论和依据来自 API |
| 会话 `/sessions` | 按用户、状态和时间筛选会话并执行撤销 | 骨架、空、筛选为空、active、expired、revoked、失败 | 打开详情、撤销一个、按允许范围撤销全部 | 读和各撤销命令独立投影 | 桌面表格；移动端关键时间与设备摘要 | 明确创建/活动/到期/撤销时间；不显示原始 Token；自撤销后退出 |
| 审计 `/audit` | 搜索、筛选、分页并查看结构化安全事件 | 骨架、空、筛选为空、失败、partial | 调整筛选、打开详情、复制 Command/Request ID、关联跳转 | 审计读取能力控制页面；敏感字段始终不展示 | 桌面表格加详情 Sheet；移动端事件列表加全屏 Sheet | URL 可恢复全部筛选；游标分页；详情不倾倒 JSON 或秘密字段 |
| 403 `/forbidden` | 解释当前账号没有页面能力 | forbidden | 返回工作台、退出 | 不展示目标页面数据和菜单 | 所有视口居中但不过度留白 | 直接 URL 与菜单隐藏结果一致，且不形成重定向循环 |
| 404 `/not-found` | 处理不存在的实体或路由 | not-found | 返回来源列表 | 不泄露无权访问实体是否存在 | 所有视口稳定 | API 的不可见资源按契约映射为 403 或 404，不由前端猜测 |

## 3. 共享页面模式

| 模式 | 使用页面 | 固定能力 | 禁止行为 |
|---|---|---|---|
| `DataTable` | 用户、组织、Site、成员、会话、审计 | URL 筛选、排序、游标分页、列显示、空态、行菜单 | 每页复制表格状态；假分页；无界加载 |
| `EntityHeader` | 用户、组织、Site 详情 | 名称、ID、状态、关键元数据、主要命令 | 超大标题；把全部详情铺在头部 |
| `EntityForm` | 创建与编辑 | RHF + Zod、字段错误、未保存保护、提交恢复 | 页面手写校验；失败后清空输入 |
| `LifecycleDialog` | 停用、恢复、删除、撤销 | 明确动词、影响摘要、原因、pending、焦点恢复 | 使用浏览器 confirm；无原因执行危险命令 |
| `MemberWorkspace` | Organization/Site 成员 | 可配置范围、共用表格与生命周期动作 | 复制两套成员实现；混用范围 ID |
| `RoleWorkspace` | Organization/Site 角色 | 角色主列表、权限树、成员使用量、完整集合保存 | 增量勾选即提交；前端计算权限闭包 |
| `DetailSheet` | 表格快速详情、审计详情 | 可访问标题、结构化字段、关联跳转 | 原始 JSON、嵌套 Sheet、秘密字段 |
| `CapabilityGuard` | 导航、路由、命令 | 使用服务端投影控制显示，保留最终 RPC 授权 | 以隐藏按钮冒充授权；本地拼接权限码 |

## 4. 模板取舍

| shadcn-admin 内容 | 决策 | 用途 |
|---|---|---|
| Sidebar、Header、主题与响应式壳层 | 迁入并适配 | 形成统一 Admin 框架，路由改为 Next.js App Router。 |
| Tasks DataTable、筛选和批量交互 | 提取模式 | 服务真实的用户、成员、会话和审计列表，不保留 Tasks 页面。 |
| Chats 分栏、滚动和窄屏交互 | 提取模式 | 服务角色主从工作区和详情交互，不保留 Chats 页面。 |
| Clerk、Zustand 认证状态 | 删除 | 使用 Auth.js 服务端 Session，不形成第二认证权威。 |
| Demo 用户、任务、聊天、应用和假统计 | 删除 | 导航、测试和生产构建中均不得出现。 |

## 5. 页面级完成定义

每一行页面只有在以下证据齐全时才可标记完成：

1. 路由、导航和深链行为通过组件及浏览器测试。
2. 初始、加载、空、错误、禁止、未找到、部分和领域状态按该行要求覆盖。
3. 所有可见命令都有能力投影、Server Action 校验、RPC 授权和错误码处理证据。
4. `1440x1000`、`1024x768`、`390x844` 截图无溢出、遮挡、闪动或布局跳动。
5. 键盘顺序、焦点恢复、可访问名称和颜色对比通过检查。
6. 数据来自契约 fixture 或真实 RPC，并清楚标记测试阶段；生产代码无 Demo/Mock 分支。
7. 两轮可见浏览器 E2E 均记录本地与 UTC 时间、步骤、截图、RPC、SQL 和日志断言。
